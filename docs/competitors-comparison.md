# Klendo, YCLIENTS и DIKIDI: что есть только у нас

Обновлено: 2026-11-23. Klendo - по коду и `docs/` (только выпущенное). YCLIENTS и DIKIDI - по их справке,
ссылки в разделе «Источники».

## Как вести документ

Здесь собраны возможности Klendo, которых нет у YCLIENTS и DIKIDI или которые у них слабее. Каждую строку
подтверждает источник: справка, страница продукта или наша проверка в их кабинете.

- **Есть** - функция есть и работает так же или лучше.
- **Частично** - функция есть, но слабее (в колонке написано, чем).
- **Нет** - в справке не найдено. Это не доказательство отсутствия: «нет» без проверки в кабинете
  остаётся гипотезой.
- **?** - не проверено.
- Новая функция Klendo после выпуска сразу получает строку в своём разделе.
- В таблицы попадает только то, что отличает Klendo. Общие для всех функции не пишем.

Ссылки: `Y:` - `https://support.yclients.ru/`, `D:` - `https://support.dikidi.net/ru/knowledge-bases/4/articles/`.

| «Любой мастер» с ценой: клиент видит, к кому и за сколько запишется, назначается мастер с этой ценой | Частично: режим есть, цена в нём не описана, показывается диапазон (`Y:32-34-825`) | Частично: 5 правил выбора, объяснения клиенту нет (`D:1090`) |
| Одна функция ранжирования для слотов и создания записи: цена слота совпадает с ценой записи | Нет (не найдено) | ? |
| Сверка цены перед записью: изменилась - запись не создаётся, клиент подтверждает новую цену | Нет (не найдено) | Нет (не найдено, `D:155`) |
| Цена у каждого слота онлайн-записи | Нет (не найдено, `Y:32-34-689`) | Частично: только при «Гибких ценах» на платном тарифе (`D:1470`) |
| Все слои цены хранятся в записи и заказе: базовая, мастера, по прайсу, скидка, итог | ? | ? |
| Пересчёт цены при смене мастера в окне записи | Частично: предупреждение и ручная правка суммы (`Y:5-8-723`) | ? |

В работе (этап 3 модуля цен): наценки по дням, часам, сезонам и праздникам с правилом «праздник заменяет
остальные», округление в пользу клиента, карта цен на неделю, проверка цены с раскладкой, массовое заполнение
цен уровня. Сравнение с конкурентами:

- У YCLIENTS цен по времени нет (не найдено).
- У DIKIDI «Гибкие цены» есть (`D:1470`): правила по датам, дням и часам, ± в %, округление до 10/50/100,
  приоритет по порядку списка.
- Чем будем сильнее DIKIDI:
    - работаем и для ручных записей (у DIKIDI гибкие цены их не касаются);
    - правило сочетания понятно без порядка списка;
    - округление скидок в пользу клиента;
    - карта цен и проверка цены;
    - сверка цены перед записью;
    - нет требования платного тарифа на функцию.
